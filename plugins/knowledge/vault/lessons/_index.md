# Lessons

A lesson is one durable finding that changes a decision in [[org-example]]. The heading of a lesson is its takeaway. The body gives the context and the outcome. Numbers that were true once are left out. A threshold stays only when it is a lasting rule.

## Source

Name your source channel here, for example a chat channel or a wiki page where teams post lessons. See [[process-example-process]].

## How to submit a lesson

1. Post it in <your lessons channel>. The lesson lands in the vault through the knowledge cron.
2. Or open a knowledge-proposal issue in the issues repo with the type "lesson".

Write the takeaway first, then the context and the outcome. Link the products, vendors, metrics and teams it touches.
