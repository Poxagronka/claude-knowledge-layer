# Knowledge index

This vault holds knowledge that is specific to <your organization>. It holds no generic tool facts and no live performance or finance metrics. A number is allowed when the entry states "as of <date>" and the source. For live numbers, use <your dashboards and planning pages>.

The files in this vault are samples. They show the format with invented content. Replace them with your own knowledge and delete what you do not need.

## How to read

- Start at [[org-example]]. Follow hub links to the topic you need.
- A hub names a team, product, system, metric, vendor, process or initiative. It links its entries.
- Entries are lessons, API facts and rules, and repos. Each links at least one hub.
- Trust order: rules > knowledge > hypotheses. For lessons: active > hypothesis > stale.
- Format contract: [[_template]].

## Categories

- Products: the `product-*` hubs. One hub per product.
- Teams: the `team-*` hubs. One hub per team.
- Systems: the `service-*` hubs. Bots, agents and internal systems.
- Metrics: the `metric-*` hubs. Metrics the organization invented or computes its own way. No hub for standard industry metrics.
- Vendors: the `vendor-*` hubs. Suppliers and external networks.
- Processes: the `process-*` hubs. How work runs.
- Playbooks: the `playbook-*` hubs.
- Initiatives: the `initiative-*` hubs. Themes with a reason and an outcome.
- Data sources: the `datasource-*` hubs. Where data and docs live.
- Competitors: the `competitor-*` hubs.
- Platforms: the `platform-*` hubs.
- Tools: the `tool-*` hubs. Warehouse tools in this repo.
- People: the `person-*` hubs. Name, role and department. No contacts.
- Example domain: [[example/knowledge]], [[example/hypotheses]] and [[example/rules]].
- API: [[api/knowledge]] and [[api/rules]]. Internal API facts and rules.
- Lessons: [[lessons/_index]] and [[lessons/example]].
- Repos: [[repos/_index]]. One file per active repo.
- Experiments: [[experiments/knowledge]]. A map of the boards where experiments live.
- Reference cards: [[confluence/EXAMPLE]]. Cards that point to durable internal pages.
