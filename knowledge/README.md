# Maintainer notes

These notes are for the maintainers of this repo.
They cover its CI workflows and its plugin distribution.
The plugin never ships this folder, so it is never installed on users' machines.
The format follows `plugins/knowledge/vault/_template.md` loosely.
The knowledge of your organization lives in the vault: `plugins/knowledge/vault/`.
Generic tool facts (Claude Code, GitHub) live here and not in the vault.

Runbook for maintainers: `docs/maintainer-runbook.md`.
