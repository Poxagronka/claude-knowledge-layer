# Graveyard

Removed block ids. A removed id is never reused. Each line holds the id, the removal date and the reason.

Format of one line (the sample below sits in a fence, so the gate does not read it):

```markdown
- `person-john-roe` (hub). Removed <YYYY-MM-DD>. Reason: <left the organization>. Source: <issue/12>.
- `^K-example-old-limit` in `example/knowledge`. Removed <YYYY-MM-DD>. Reason: <contradicted by a primary page>. Source: <pr/7>.
```
